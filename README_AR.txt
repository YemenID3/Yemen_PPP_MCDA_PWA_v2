دليل النشر والتثبيت السريع لتطبيق الجوال (PWA)
================================================
تطبيق: الإطار الرقمي لحوكمة شراكات توليد الكهرباء باليمن (MCDA-WSM)
تطوير وتطبيق: Yemen ID - Challengers Team | جامعة ذمار | المؤتمر العلمي الدولي الأول (2027)

محتويات الحزمة:
- index.html      : ملف التطبيق الكامل (يدعم العمل دون إنترنت ومُدمج به الشعارات الثلاثة الرسمية).
- manifest.json   : ملف تعريف التطبيق لتثبيته بأيقونة مستقلة على Android وiOS.
- sw.js           : ملف الخدمة الخلفية (Service Worker) لتشغيل التطبيق دون إنترنت.
- assets/         : صور الشعارات الرسمية وأيقونات التطبيق (192x192 و512x512).

طريقة 1: التشغيل المباشر على الحاسوب أو الجوال (دون إنترنت):
- افتح ملف index.html مباشرة بأي متصفح (Chrome / Edge / Safari).

طريقة 2: النشر المجاني الفوري خلال 60 ثانية (Netlify Drop):
1. فك ضغط هذا الملف (Yemen_PPP_MCDA_PWA_v2.zip) في مجلد على جهازك.
2. افتح الموقع: https://app.netlify.com/drop
3. اسحب المجلد الكامل وأفلته في المربع المخصص؛ سيصدر لك رابط HTTPS آمن ومجاني فوراً.
4. افتح الرابط من جوالك واضغط (إضافة إلى الشاشة الرئيسية / تثبيت التطبيق).

طريقة 3: النشر الدائم المجاني (GitHub Pages):
1. أنشئ مستودعاً (Repository) عاماً على GitHub.
2. ارفع محتويات هذا المجلد إليه (index.html وmanifest.json وsw.js ومجلد assets).
3. من الإعدادات (Settings -> Pages) اختر فرع main ثم Save؛ سيصدر لك رابطك الدائم المجاني.

طريقة 4: استخراج ملف أندرويد (APK) مجاناً (اختياري):
- بعد الحصول على رابط HTTPS من Netlify أو GitHub، الصق الرابط في موقع https://www.pwabuilder.com
  واختر Package for Stores -> Android لتنزيل ملف APK مباشر.
